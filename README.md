Student Grade Management Program

A C++ program for managing student grades and calculating final results.
Features
    Add students manually
    Generate students and grades randomly
    Calculate final grade using homework average or median
    Read student data from kursiokai.txt
    Validate input and grades
    Display student results
Final Grade
Final = 0.4 × Homework Average + 0.6 × Exam
Final = 0.4 × Homework Median + 0.6 × Exam
